# Station assets

User-supplied downloads, copied without modifying the originals.

- `desk.glb`: Desk by dook — EtJlOllzbf.
- `file-cabinet.glb`: File Cabinet by J-Toastie — 9732ObD3OY.
- `fluorescent-fixture.glb`: Flourescent Fixture by Colin McKibben — b434Bd1ozKE.

Active surface sets: Bricks082A, PaintedPlaster005, Tiles051, Carpet006 and WoodFloor041. The station loads 512px color, OpenGL normal and roughness derivatives from `../../textures/station-lite/`. Unused original texture copies, material-tool exports and the retired exterior assets were removed from the runtime project; attribution is retained here.

Creator names come from the supplied filenames; retain the original asset licenses when distributing.
